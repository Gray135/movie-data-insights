# 🎬 Power BI Dashboard – Film ROI Analysis

This folder contains the **Power BI dashboard file** for the Film ROI Analysis project.  
It turns the SQL-analyzed dataset into interactive visuals that highlight drivers of movie profitability.

## File Included
- `movie_roi_dashboard_update.pbix` – Power BI file with visuals, slicers, DAX formulas, and the data model.

## How to Use
1. [Download the PBIX file](movie_roi_dashboard_update.pbix) (click the link, then **Raw** to download).  
2. Open it in **Power BI Desktop**.  
3. Explore pages covering:
   - ROI performance overview  
   - Top 10 films by ROI and revenue  
   - Genre and studio analysis  
   - Trends by release year and runtime  

---

⚠️ Note: `.pbix` files can’t be previewed on GitHub. You’ll need **Power BI Desktop** to open and interact with the dashboard.
