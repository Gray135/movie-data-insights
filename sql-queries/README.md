# SQL Queries

This folder contains all queries used to clean, analyze, and benchmark ROI performance.  
Each file follows the pattern: **question → SQL → sample output → insights.**

**Files include:**
- `top_movies.sql` – top 10 ROI films with director, studio, lead actor
- `budget_ratio.sql` – ROI calculation across all films
- `genre_summary.sql` – ROI benchmarks by genre
- `compare_to_avg.sql` – films compared to genre averages
- `production_companies.sql` – high-ROI studios and production companies
- `avg_vs_actual.sql` – how top 10 films differ from dataset averages
- `release_year.sql` – trends in ROI by release year and runtime
- `view_movie_data.sql` – consolidated cleaned dataset for dashboards
